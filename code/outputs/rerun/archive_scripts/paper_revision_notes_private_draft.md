## 2. 贡献点（替换原第 9 段）
本文面向工程变更单的原因与事项互补结构提出字段协同神经主题模型 FC-NTM，主要贡献包括：
1. **问题与数据层面**：首次把施工变更单建模为"原因字段 + 变更事项字段"的字段级结构化短文本问题，并给出该语料中 285/577（49.4%）文档缺失原因字段的实证统计，把"字段缺失"确立为建模的一等公民。
2. **方法层面**：将双字段显式建模为两个条件变分流并共享一个主题—词解码器；设计跨字段重构与字段一致性（对称 JS）正则，使一个字段的主题推断能够利用另一字段的语义补充；当某字段缺失时，该流回退到先验而非强制编码空文本，从而对部分记录保持鲁棒。
3. **训练与读出层面**：引入字段级词掩码与验证集早停，把字段文本视为部分观测；提出基于文档—主题后验软归属的类 TF-IDF 读出；并进一步引入预训练词向量解码器，形成基础 FC-NTM、升级读出 FC-NTM-cTFIDF 与最终配置 FC-NTM-Emb 三档对照。
4. **评价层面**：提出字段视角主题一致性协议，分别在原因词表与事项词表上计算 C_V/NPMI/UMass，并报告字段间主题对齐度，用于诊断"全局指标好看但某一字段主题塌陷"的问题。
5. **实证层面**：在私有变更单语料与 GitHub issues 公开语料上，FC-NTM-Emb 在全局一致性上达到或超过 BTM/NMF/ETM/CTM/CombinedTM/BERTopic，同时在字段视角上保持可解释的语义分工。

## 3. 相关工作 2.2 节需新增的段落
多视角主题建模已有较多研究。Kurle 等提出多源神经变分推断，允许不同信息源的后验通过散度相互约束[9]；Zhang 等对多视图数据提出鲁棒主题模型，假设视图间共享主题比例[10]；Pergola 等针对评论把观点与情节解耦[11]；Liu 等把短文本的局部语料与全局知识构造为双视图模型[12]。**与本文最接近的是面向评论的方面级神经主题模型 VALTA/VALDA（Esmaeili 等，AISTATS 2019）**：它们把评论按句级方面结构化，并为每个方面学习方面特定主题。但 VALTA 假设方面标签/分配在训练时可得且每个方面均有观测；本文的字段是文档级记录字段而非句级方面，且允许整个原因字段缺失，模型必须在该字段不可观测时回退到先验并仍能推断主题。**多字段相关主题模型（SDM 2009）**同样对多字段联合建模，但属于非神经的全局图模型，且不处理字段缺失。**子文档神经主题模型 SubNTM（Knowledge-Based Systems 2025）**在文档与子文档两级学习主题，但子文档是切分而非语义字段。**字段感知变分自编码器 FVAE（IEEE 2022）**对多字段用户数据为每个字段建模独立多项分布，但其目标是用户表征而非主题一致性。结构性主题模型能够把文档级协变量纳入先验[21]，但协变量不是与正文具有语义分工的第二个文本字段。本文通过双字段流、跨字段重构、字段一致性正则与缺失字段先验回退，把原因与事项组织进共享主题空间，这一组合在现有文献中未见相同表述。

## 4. 位（biterm）正则的定位（必须写进消融，不能写成创新）
BigARTM 的 `biterms_phi` 正则、BCK-TM（The Computer Journal 2020）、GraphBTM（EMNLP 2018）与 TRNMF（IEEE 2020）均已利用词对共现正则化主题模型，因此本文不主张 biterm 项的新颖性。消融显示：在线性解码器下，biterm 正则（λ=0.05）能把 FC-NTM-cTFIDF 的 NPMI 从 +0.003 提升到 +0.012；但在预训练词向量解码器下 biterm 项反而有害（λ=0.05 时 β 读出 NPMI 由 +0.098 降至 −0.065），故最终配置不启用 biterm。

## 5. 局限性段落修订
删除"在通用 C_V 上 FC-NTM 低于 BTM 与 NMF"这一条（FC-NTM-Emb 已超过 BTM）。保留并强化：
- 私有语料仅 577 条且来自单一项目群，字段视角结论需更多项目验证；
- 私有语料为 in-sample 评价（run_fcntm_train.py 以全量语料训练与评估），泛化证据以 GitHub issues 的 6000/2000 train/test 拆分为准；
- 神经模型的跨种子主题稳定性仍低于 NMF；
- 词掩码率与 KL 权重为经验取值；
- 公开基准中验证早停占用 20% 训练文档，与基线存在样本使用差异。
