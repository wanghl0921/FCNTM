
# 模型改进核查（2026-09-10）

## 结论
模型**可以改进，但要换到它真正擅长的轴**：跨字段缺失填补，而不是硬追全局 C_V/NPMI 超过 BTM。

## 诊断
1. 全局一致性：线性 FC-NTM 在公开留出集 0.683/0.222，略低于 BTM 0.706/0.230；embedding decoder 的"胜利"是 in-sample + 锐化超参的产物。
2. 根因：私有语料中位数 7 词，短文本极度稀疏；49.4% 文档缺原因字段，给训练引入噪声。
3. 消融：只在成对文档上训练（FC-NTM-Paired）比全量训练 NPMI 更好（+0.014 vs −0.038），说明缺失字段文档在拖累全局指标。

## 试过但无效的改进
- **字段感知伪文档增强**（用事项字段检索近邻聚合原因字段）：seed 11 上 β NPMI −0.039 vs 基线 −0.025，无提升。
- **提高一致性权重**（0.5→1.0）：留出填补 recall 0.098 vs 基线 0.101，无提升。

## 有效的改进：加强跨字段重建
私有语料，成对文档，用"事项流"预测真实原因词的 recall@10（in-sample 消融）：

| 模型 | item_recall | item-cause 余弦 |
| --- | --- | --- |
| FC-NTM（含跨字段重建） | 0.229 | 0.817 |
| FC-NTM−XRec（去掉跨字段重建） | 0.123 | 0.402 |

→ **跨字段重建是缺失字段填补能力的核心机制，去掉后 recall 腰斩。**

留出集调参（80/20，3 种子，每种子约 58 篇成对留出文档）：

| 配置 | mean item_recall | std |
| --- | --- | --- |
| cause_recon_weight=2.0 (recon2) | **0.1251** | 0.0141 |
| recon2 + consistency=1.0 | 0.1238 | 0.0376 |
| 只训练成对文档 (paired) | 0.1111 | 0.0168 |
| 基线 (recon=0.6, cons=0.5) | 0.1007 | 0.0306 |
| consistency=1.0 | 0.0976 | 0.0475 |

recon2 − base 逐种子差异：+0.054, −0.002, +0.021；均值 +0.024，标准差 0.028。
**方向一致、幅度约 +25%，但 3 个种子达不到统计显著（t≈1.5），需要更多种子和更大的评价集。**

## 建议的论文定位（诚实且可发表）
- 主贡献：面向缺失字段的字段协同神经主题模型 + **跨字段主题填补任务与指标**。
- 全局一致性：如实报告为与 BTM 相当/略低；在神经主题模型中领先（公开集 0.683/0.222 高于 CombinedTM 0.618/0.176、NeuralLDA 0.591/0.124、ETM 0.503/−0.391、NMF 0.614/0.164）。
- 新增实验：
  1. 跨字段填补的公开规模验证（GitHub：用标题预测正文词，2000 篇测试文档）；
  2. 10 个种子 + 5 折交叉验证，给出显著性；
  3. 单流基线（ProdLDA/BTM/ETM）无法做跨字段填补，作为结构性优势说明；
  4. 缺失字段分组评价（有/无原因字段文档分别报告）。
- 模型默认配置建议改为 **cause_recon_weight=2.0**（在留出填补指标上最优，且方差最小）。
